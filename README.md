# vBot

A Geometry Dash bot mod made by Neo_ using [Geode](https://geode-sdk.org/).

# Features

- Geometry Dash bot functionality
- Built for Geometry Dash 2.2081
- Supports Windows and Android

# Installation

1. Install [Geode](https://geode-sdk.org/).
2. Download the latest "Neogd.vBot.geode" file from the [Releases](https://github.com/NeoGd-Official/vBot/releases) page.
5. Install the ".geode" file through Geode.
6. Launch Geometry Dash.
